# O que é um serviço WEB
Ela funciona por um conjunto de protocolos.
# Exemplos de protocolo
- HTTP: Hypertext Transfer Protocol(Documentos com referencias a outros documentos). Define uma relação de cliente e servidor, como as informações serão trocadas entre um cliente e servidor.
- FTP: File transfer protocol
- SMTP: Simple mail transfer protocol, um dos protocolos para transferencia de menssagens de email
# O que é um protocolo
Um padrão, um acordo, que segue regras conhecidas entre as partes que estão transmitindo as informações.
## Relação com telefone sem fio
O payload é o conteúdo que está sendo transmitido.
Cada criança é uma proxie.
Todas seguem uma mesma regra.
# Protocolo TCP
Garante que as informações vão chegar no destinatário.
Pode ser opcional dependendo do caso, onde o custo para a verificação e retransmissão em caso de erro, pode ser muito alto, e aumentar o delay. Tipo em um meet. Para estes casos usa o UDP.
# Protocolo UDP
User Datagram Protocol.
Não depende de conferência entre as partes envolvidas.
## TCP Recovery
Garantia que o conteúdo vai estar correto, fazendo verificações de integridade.
# Protocolo IP
Internet protocol. Protocolo para transitar informações entre a internet.
