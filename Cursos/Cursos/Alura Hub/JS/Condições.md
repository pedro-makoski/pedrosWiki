```js
if(condition) {

}
```
A condition deve ser algo que retorna um valor boolano. Ou algo que pode ser null ou não, para verificar. E depois segue o código.
Você pode entender um pouco mais condições aqui: [[If e else]]. 
No JS tem operadores de comparação, são eles:
```md
- == os valores são iguais?
- === os valores são estritamente iguais, não só iguais, mas também do mesmo tipo?
- < - é menor
- > - é maior
- <= é menor igual 
- >= é maior igual
- != é diferente?
- !== é estritamente diferente.
```
Também temos os operadores lógicos, que comparam duas condições true ou false:
```md
- OR - || - pelo menos uma das condições deve ser verdadeira
- AND - && - todas as condições devem ser verdadeiras. 
```
