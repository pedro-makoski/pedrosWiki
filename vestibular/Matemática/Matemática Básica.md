# Axiomas
São regras que são verdadeiros, sem necessitar de demonstração.
- Coisas iguais a mesmas coisas são iguais entre si
- Coisas iguais adicionado a coisas iguais formam coisas iguais 
- Coisas iguais subtraída de coisas iguais formam coisas iguais 
# O que são multiplos
- Todos os valores que são resultado deste vezes um número natural
