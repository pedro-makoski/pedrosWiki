 Sobre o isolamento de estilos: cada componente tem uma configuração de encapsulamento de visualização. Existem três modos: `Emulated`, `ShadowDom` e `None`. Por padrão, o Angular usa o modo `Emulated`, onde os estilos do componente só se aplicam aos elementos definidos no template desse componente. Isso previne que estilos vazem e afetem outros componentes.
 Mas se você quiser, pode mudar para o modo `ShadowDom`. Nesse caso, os estilos ficam restritos dentro de um shadow tree, protegendo ainda mais seu componente. Ou, se preferir, use o modo `None` para desativar o encapsulamento e tratar os estilos do componente como globais.
