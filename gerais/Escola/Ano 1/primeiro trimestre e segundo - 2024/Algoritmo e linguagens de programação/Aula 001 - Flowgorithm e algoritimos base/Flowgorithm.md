Flowgorithm - programa para programação via fluxograma. para aprendizado de programação.
## Processo geral de uma programação

entrada - obter valores do usuário.

processamento - processar os valores do usuário, fazer acontecer o que o usuário precisa, tipo desde somar dois valores até resolver problemas mais complexos.

<aside style="background-color:rgba(0, 100, 100, 0.5); padding:20px; border-radius:10px;"> 👉 onde se falta uma coisinha tanto entrada quanto no processamento, já pode dar errado.
</aside>


saída - mostrar para o usuário - o resultado do programa.

## Símbolos no Flowgorithms

Oval - circulo, um quadrado bem arredondado: início/fim, indica o processo, e quando termina.

quadrado - os processos.

flechas - demonstram para aonde o fluxo está indo.

losango - alternativa - decisão se faz algo ou não.

circulo - conector - para mostrar que para aonde o programa contínua. a sequencia do código.
