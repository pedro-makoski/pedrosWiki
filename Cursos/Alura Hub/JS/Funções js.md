Segue uma estrutura simples:
```js
function nameName() {
	return 
}
```
O declarador: function, seguido pelo nome da função nameName, seguido pelos parênteses onde estão os parâmetros. E depois entre chaves deve ter o código que vai ser executado quando a função for chamada, e também opcionalmente o retorno daquela função, que pode ser nada ou alguma outra variável.

# console.log
