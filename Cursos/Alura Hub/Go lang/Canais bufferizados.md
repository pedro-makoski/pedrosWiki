# O que é buffer
Local com tamanho delimitado, para armazenamento temporário.
# Como definir
Coloque no segundo parâmetro do make a quantidade de items que cabem neste channel.
# Como funciona
Bloqueia a entrada de itens numa channel, até que seja liberado, um espaço delimitado no channel.
# Len e cap
len - quantos itens tem no channel
cap - quantos itens cabem no channel
