# Atribuição
Atribui algo a uma variável. representada por =. 
# Adição
Você pode adicionar valores com o sinal +. Você também pode somar um valor a uma variável e atribuir a essa variável a soma tudo junto com x += y que seria x = x + y.
# Subtração 
A expressão - faz a subtração. -= iguala variável a subtração entre a variável em um valor. x-=5 => x = x-5. 
# Multiplicação
Da mesma forma, ``x*y`` multiplica, já x*=y atribui a multiplicação a x, junto com a multiplicação.
# Divisão
Faz a mesma coisa. x/y divide x por y, e x/=y dividade x por y e atribui a x. 
# Incremento 
x+= 1, é a mesma coisa que x++. Ou seja, x++, atribui a x, o valor de x mais o valor 1.
# Decremento
x-=1, é o mesmo que x--. Ou seja, x--, atribui a x, o valor de x menos 1. 
# pré-incremento 
Primeiro é atribuído depois é feito outras ações. Diferente do pos-incremento, que ele faz as ações e depois atribui, o pré-incremento, representado assim ++x, atribui o valor de x+1, antes de tudo.

# Operadores de Comparação 
Retorna um valor booleano, se uma comparação for verdadeira ou for falsa, verificando se uma afirmação é verdadeira ou não.
![[Pasted image 20241007144134.png]]
Perceba que 15 == '15', retorna true. Porém se formos fazer o estritamente idêntico 15 === '15', retorna false. 
# Operadores lógicos
Atuam em conjunto com os valores de comparação, ou booleanos, pois eles também retornam valores booleanos.
