# o que é a internet?
A internet é uma rede mundial de computadores, também chamado(em inglês) **_World Wide Web_**, com a famosa sigla www. Os continentes estão conectados por meio de cabos submersos no mar, chamado cabos submarinos.
# Protocolos da internet
É necessário criar regras na internet, para que tenha um padrão de conexão entre sistemas diferentes operadoras, essas regras são os protocolos que podem garantir a segurança, o trafego dos dados e comunicação entre os computadores.
Veja alguns protocolos da internet:
## IP(Internet Protocol Adress - Endereço de protocolo de internet)
Endereço de um computador, impressora e celular; para acontecer a comunicação entre os mesmos. O IP é uma sequência de números. São 32 bits, ou 4 bytes, cada byte é separado normalmente por um ponto. Um byte vai de 0 a 255. Os primeiros 2 bytes são chamados de rede(os que tem esses mesmos valores, são da mesma rede), e os outros 2 bytes são chamados de host(define a maquina indistinguível da rede). 
## TCP/IP - TCP(Transmission Control Protocol) e IP(Internet protocol)
O TCP garante controle da transmissão, enquanto o IP garante o endereço correto. O TCP/IP é um modelo de camadas que serve como base para a visualização e interação dos dados em detrimento de vários protocolos.

## HTTP(Hyper Text Transport Protocol)
Na camada de aplicação é processado dados de outros protocolos de acordo com seu tipo. Um exemplo é o HTTP, que é usado para a transmissão de documentos hipermídia, como por exemplo O HTML.
Nele é feita a transmissão de dados, assim fazendo uma transmissão, uma conexão entre servidor e navegador. A relação possível com o HTTP é chamada de cliente-servidor.

## FTP(File Transfer Protocol ou Protocolo de Transferência de Arquivos)

## SSH(Secure Shell ou Cápsula Segura)
Com ele é possível fazer um controle seguro de um servidor remotamente, de forma bem segura. Nela é feita uma autenticação para saber se a conexão é segura.
# DNS(Domain Name System ou Sistema de Nomes de Domínio)
Permite com que você acesse os sites pelos nomes deles, e não pelos seus IPs ou endereços do servidor. Então o DNS traduz o endereço no IP, para fazer a comunicação do navegador e o servidor.
