Não são obrigatórios. Mas quando aparecem trazem mais informações sobre elas. Os essências são o sujeito e o predicado.
# Adjunto Adverbial
O adverbio faz parte. É o termo que traz circunstância ao verbo.
```
Hoje - adjunto adverbial de tempo
Estudei
Muito - adjunto adverbial de intensidade
No canal do Professor Noslen - adjunto adverbial de tempo
```
# Adjunto Adnominal
É o termo que se refere ao núcleo do elemento sintático, geralmente substantivo.
```
Os - sujeito e adjunto adnominal
cachorros - sujeito 
raivosos - sujeito- adjunto adnominal
morderam - V.T.D
a - - objeto direto e adjunto adnominal
cerca - objeto direto
com força - Adjunto Adverbial
```
# Complemento nominal
É o termo que completa o sentido de um substantivo abstrato, sempre iniciado por preposição.
```
eu - Sujeito
tenho - V.T.D
medo - Objeto Direto
de altura - complemento nominal.
```
É tipo um objeto indireto, porém complementa o sentido de um substântivo.
# Predicativos
Características.
## Predicativo do Sujeito
É uma característica momentânea do sujeito, normalmente está dentro do predicado. Quando é passado para outro lugar usa-se a vírgula.
```
Todos - Sujeito
Correram - V.T.D
Entusiasmados - predicátivo do sujeito
A
Maratona
```
## Predicativo do Objeto
É uma característica momentânea do objeto.
```
Comprei - V.T.D
Um Carro - Objeto Direto
Quebrado - predicátivo do objeto
```
# Vocativo
É o termo que evoca, chama algo ou alguém na oração, sempre isolado por vírgula. Sempre é isolado por vírgula.
# Aposto
É o termo responsável por explicar ou justificar um elemento anterior a ele.
Tipos de aposto:
- Distributivo: retoma dois elementos citados anteriormente. Tipo a relação ambos e **um** e **outro**
- Explicativo: explica algum termo, fica entre vírgulas
- Enumerativo: enumera: Normalmente vem depois de :.
- Comparativo: compara o que foi dito anteriormente com outro.
- Oração Apositiva: uma oração completa que ajuda a explicar
- Recapitulativo / Resumidor: resume o que foi dito anterior, exemplo: tudo. 
- Especificativo: específica o termo anterior. Exemplo: o escrito **Guimarães Rosa**...
# Agente da Passiva
A voz passiva é quando o sujeito sofre a ação. O agente da passiva seria o que realiza a ação
```
O brigadeiro - sujeito
Foi comido - locução verbal
pelo Noslen - Agente da Passiva
```
