**Responsividade** é o comportamento de dar resposta, comportamento responsivo, de solucionar, tomar a responsabilidade para si, recepcionar questões e dúvidas no intuito de respondê-las. 

É a capacidade do site se comportar em diferentes tamanhos de tela. 
# Botsrap 
Ajuda no processo de responsividade. Agilizando o processo.
ele é um **framework** que disponibiliza várias classes pré-definidas de CSS com recursos embutidos de programação JavaScript, para que possamos usar em nossos projetos de forma simples e única, fazendo com que o site seja **_responsivo_** e se adapte para qualquer tipo de tela.
