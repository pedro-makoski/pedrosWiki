Perceba que aquele código acima funciona. Você também pode adicionar apenas um &, para colocar outra expressão. E mesmo que você coloque em linhas diferentes, contato que você não feche com ponto e vírgula, ele funcionara corretamente. Depois do ponto e vírgula pode ser adicionado um else, que funciona da mesma forma. Quando você coloca um **&**, é como se fosse apenas um comando após o if.
As chaves podem ser usadas da mesma forma, ao coloca-las, vocês diz para o computador, que tudo que está nela, é um único comando, só que dai você não precisa colocar & depois de tudo. O ponto e vírgula no final das chaves não é necessário, isso graças a ASI.

Com a criação do Else if, se cria o que se chama estrutura condicional aninhada.
