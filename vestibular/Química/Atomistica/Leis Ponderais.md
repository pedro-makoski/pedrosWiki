Leis das composições químicas. Leis que falam sobre as relações de massa.
# Lei Da Conservação das massas
Proposto por Lavousier, afirma que a soma das massas dos reagentes é igual a soma das massas dos produtos.
# Lei de Proust/Lei das proporções definidas/constantes
Proposta por Proust, afirma que a proporção entre reagentes é produtos é a mesma sempre para que haja a reação completa.
# Lei de Dalton/Lei das proporções multiplas 
A partir de uma composição formada por dois elementos químicos, caso um se mantenha fixo o outro só pode aumentar em proporções fixas de números inteiros.
