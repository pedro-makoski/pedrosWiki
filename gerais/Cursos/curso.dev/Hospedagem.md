- Os serviços de hospedagem foram criados para hospedar os seus arquivos 
# Evolução
- Primeiro os seus computadores eram usados como hospedagem 
- Computadores que não desligam e mais fortes, e que era feito o deploy para esse servidores implantando o novo código no servidor
- Depois era feito o SSH ou usado Windows server para fazer os códigos diretos no servidor
- Com o surgimento do github, foi possível fazer alterações no servidor a partir do repositório.
- Agora a maquina do programador envia o código pro Github, que envia para um código de C.I.(Continuous integration, onde era testado), e depois envia para outra maquina que é feito o Build, e depois é enviado para o servidor
# Deploy com a Vercel
- Crie uma conta na vercel, conecte com o Github
- Coloque o repositório
- E clique no botão para fazer o deploy, e veja o build acontecer
- Continuous Deployment - C.D. - a vercel recebe que algo mudou e altera no vercel. E cria um para cada commit novo e branch nova.
# Princípio do privilégio minimo
Atribuir a menor a quantidade de acessos e controles que uma conta pode ter dentro de quaisquers sistemas.
