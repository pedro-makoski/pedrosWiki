# A e An
O an é usado apenas quando o próximo som a ser feito tem som de vogal. Não precisa ser vogal necessariamente, por exemplo, se for um letra muda e a próxima é uma vogal, também é usado an. 
# Som do th
There, the, those/that, they/them, than: se tem o som de d. Tudo que não tem significado próprio tem som de d. 
Mas agora quando não se tem isso, se usa um som de f, só que com a língua um pouco mais presa.
