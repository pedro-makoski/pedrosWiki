Conjunto de ferramentas trabalhar com o Angular. Uma das suas funções é poder compilar o código Angular em um código para navegador, criar um projeto Angular e assim vai.
# Como criar
Execute 
```bash
ng new <nome-do-projeto>
```
Escolha as folhas de estilo que você deseja. 
A próxima pergunta se você vai trabalhar com SSR.
# Como executar
```bash
ng serve
```
# Arquivos
Tem no src o index.html e styles.css que são os arquivos base a tudo. Tem também o app que é o local onde vai estar tudo nele que contem seus arquivos e estilos.
