3. Busque inspirações
4. Design em si
# Fundamentos UI
User interface.
Diagramação - alinhar os elementos no local correto. Clique shift+g para alinhar nas colunas os elementos.
Computador - 12 colunas
Tablet - 8 colunas
Mobile - 4 colunas.
Tenha uma margem no grid da diagramação.
**Não coloque mais de duas fontes no seu projeto**.
Tamanho dos botões - entre 16 e 18 pixels.
Utilize multiplos 8 e 4 pixels. 
# Atalhos 
shift+A - cria um agrupamento.
C - comentários.
ctrl + roda do mouse  -> zoom
p -> caneta
t -> texto
o -> cria circulo
r -> retangulo
