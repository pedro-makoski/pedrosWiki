# Substância
Entidade com composição e atributos únicos. Podem ser:
- **Substância simples**: apenas um tipo de molécula(O2, H2, N2)
- **Substância composta**: formado por mais de um tipo de molécula(CO2, H2O, C6H12O6)
# Misturas x Substâncias puras
As misturas são formados por mais de uma substância, enquanto a substância pura é apenas apenas uma substância.

A água destilada é uma substância pura, enquanto a água potável ou mineral é uma mistura com outros compostos.
# Fase
Porção visível e uniforme(é igual em cada seleção) da matéria não necessariamente retilíneo. 
# Homogêneo x Heterogêneo
## Homogêneo 
- Apenas uma fase
- As moléculas das substâncias envolvidas interagem molecularmente ou atomicamente falando
## Heterogêneo
- Mais de uma fase
- As moléculas das substâncias se diferem de forma visível
- Alguns itens, como sangue e leite, são chamados de calóides, no qual parecem homogêneos porém a olho microscópico que são heterogêneos.
