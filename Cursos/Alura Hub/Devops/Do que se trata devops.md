DevOps é uma filosofia e conjunto de práticas que integram os times de desenvolvimentos e o time de operações.
# Fases do devops
1. Planejar: levantar os requisitos e necessidades, e quais são as funcionalidades realmente importantes.
2. Codificar.
3. Integra e testa
4. Libera e implanta
5. Operar e monitorar, para cuidar do sistema para verificar se não tem nenhum erro. 
# CI/CD - Integração continua e a entrega continua 
CI - Integrado e testado constantemente.
CD - Trabalhar para que novas funcionalidades entrem de forma mais rápida.
