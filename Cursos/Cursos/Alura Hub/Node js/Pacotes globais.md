Os pacotes globais, podem ser acessados por todas as pastas do seu computador. Permitindo maior facilidade na hora de importar o projeto, por outro lado isso é ruim, pois não é especificado a versão do json-server no projeto.
Você fazer com que se global, digitando --global ou -g na linha de comando ao instalar.

Os pacotes globais podem ser usados sem o prefixo npx. Já locais precisam. 
Para desinstalar pacotes globais:
```sh
npm uninstall -g <pacote>
``` 
	E para instalar pacotes globais:
```sh
npm install -g <pacote>
```
