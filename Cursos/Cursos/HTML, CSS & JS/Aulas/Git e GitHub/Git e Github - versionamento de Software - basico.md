## Git x GitHub
---
*Diferença mais superficial*
### Repositório local/remoto
- **Local**: se cria no seu computador.
- **Remoto**: se cria on-line. 
### Gerenciador de versões - Git
Quando se cria um projeto, você pode fazer atualizações nele, mas e se não funcionar a nova versão, e você não fez um backup. Para isso se usa um **gerenciador de versões**, e tem a qualidade de não ter que ficar criando várias pastas copia de backup.

Um dos softwares que faz o versionamento de versões é o **Git**. Ele é um software livre, grátis, open-source. Ele foi criado pelo mesmo criador do **Linux**. Portanto o Git é um software que faz o versionamento das suas aplicações. 

Quando é feito o versionamento da sua aplicação, o Git junta tudo no que é chamado de **Repositório local**, com todo o seu versionamento.
### Servidor - nuvem - backup - GitHub
E se o seu computador estragar, você pede os arquivos de código que você fez. Ou supondo que você queira mostrar seu site para um amigo seu. Para esse tipo de coisa se usa uma hospedagem, mas isso é pago, você me diz. Não o GitHub é gratuito e faz tudo isso para você.

E com isso o GitHub cria o chamado **Repositório remoto**. O GitHub permite você trabalhar em equipe. Onde cada um tem o seu próprio repositório local. E esses repositórios locais, trabalham para um repositório remoto, já que é uma mesma equipe.

## Usar repositórios em outros locais
---
- No outro computador é necessário ter instalado o Git, GitHub, Google Chrome(ou outro navegador) e VScode.
- No Git Hub desktop > file > options > accounts > Sign in.
- Fazer login com sua conta.
- Vai em File > options  > Git, clique nos inputs e depois em save.
- Clique no repositório que você quer clonar. E clique em clonar (nome do repositório).
- No segundo input de texto, escolha o local que você vai salvar, clicando em choose. 
### Remover do computador
- Clique em repositório > remove > marque a opção recicle bin para excluir.
- Depois clique em file > Options > Accounts > Sign Out, para sair da conta no GitHub desktop.
- Depois na aba Git > selecione os campos, apague os textos e clique em salvar.
- Depois esvazie a lixeira.
