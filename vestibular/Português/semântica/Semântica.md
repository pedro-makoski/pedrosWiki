# Linguagem x Língua
Língua - léxico e gramática.
Linguagem - tudo que pode ser usado para expressar uma ideia. Desde verbal quanto não verbal.
# Sentidos denotativos x conotativos
Denotação - sentido literal. Significado real. 
Conotativo - sentido figurado. Pode depender o sentido  a partir do contexto.
# Relação de Sinonímia
Relação estabelecida entre duas ou mais palavras que apresentam significados iguais ou semelhantes dentro de um contexto.
# Relação de Antonímia 
Relação estabelecidas entre duas ou mais palavras que apresentam significados diferentes, contrários dentro de um contexto.
Exemplo: Joãozinho era **bondoso**, já carlos **tinhoso**.
# Relação de Homonímia
Palavras ou com som ou/e com escrita igual só que com significados diferentes.
Homógrafos ou heterofonas - palavras iguais na escrita porém diferentes na pronuncia.
Homófonas  ou heterografas- sons iguais e sentidos diferentes.
# Relação De Paronímia
Palavras com significados diferentes, mas com pronuncias semelhantes mas não iguais.
# Relação De Polissemia
Caracteriza-se pela propriedade que uma palavra pode apresentar mais de um significado.
# Hiperônimo
Palavras que possuem dentro dela outras palavras. Tipo Animal que é hiperônimo à inseto. 
# Hipônimo
É um vocábulo mais específico, possui o sentido mais restrito que os hiperônimos. 
# Ambiguidade
É entendida quando uma palavra ou um grupo possui mais de um significado.
# Sentido e significado
Significado - é o referente, ou a coisa ao qual a palavra se representa no mundo(denotativo).
	É o sentido da palavra diretamente no seu sentido literal.
Sentido - é o significado que a palavra pode assumir dentro de contextos diferentes(conotativo).
Significante - é o que possui sentido.
# Variações linguísticas
Diafásica - variando pelo âmbito do contexto, como algo formal e informal. Falamos de formas diferentes para pessoas diferentes.
Diatópica - Mudanças regionais 
Diastrática - Variação de acordo com a cultura, história ou grupo social.
# Expressões idiomáticas
Sentido conotativo - não literal. Funcionam para regiões específicas.
