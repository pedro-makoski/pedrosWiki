O **POO**(programação orientada a objetos), tem como principio categorizar e concentrar tudo relacionada, em um item só, chamado de classe. Uma classe concentra as características, em atributos, e as ações realizadas em métodos. Para fazer os atributos e os métodos é necessário abstrair, fazer uma abstração.

Em uma **abstração** você se concentra nos aspectos essenciais, e ignora características menos importantes ou acidentais. Uma classe é uma abstração de entidades existentes. 

## Diagrama de classes 
Faz parte da **UML** (_Unified Modeling Language_ ou Linguagem de Modelagem Unificada), é um conceito que representa uma classe, uma entidades, com o nome da entidade, os atributos(características) e embaixo os métodos(as ações executáveis).

A UML foi uma padronização para escrita e representação de ideias, no desenvolvimento de Software.
## Uma classe não é um objeto é uma representação de entidade
O objeto surge quando criamos uma estrutura de classe para criar uma instância de entidade. O objeto criado ou instanciado passa a ter todas as propriedades e funcionalidades que a classe especificou.
## Constructor ou construtor 
É um método especial na classe que é sempre executado automaticamente, no momento em que o objeto é instanciado. Esse método é convocado apenas na inicialização do projeto. 
## Invocar
Quando é executado um método ou função.
## Importante
Um nome de uma classe, uma entidade, sempre começa com uma letra maiúscula. 
## This
Usado no JavaScript para colocar propriedades à uma classe, por exemplo this.nome. Também podemos acessar funções dentro de uma classe, chamando a função com o this.funcao(), ou acessar uma propriedade definida no constructor, this.idade, por exemplo.
## New
Usado para instanciar uma classe.
