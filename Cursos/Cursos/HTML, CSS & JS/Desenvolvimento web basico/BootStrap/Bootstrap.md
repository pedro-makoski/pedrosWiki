A sua criação tem como característica fundamental a aplicação de técnicas de design nos componentes para melhorar a interface e experiência do usuário, além de sua auto-adaptação para qualquer tela, tornando o site _responsivo_.
# Estrutura do diretório do Bootstrap
![[Pasted image 20241125144019.png]]
Nos arquivos **CSS**, temos classes com propriedades definidas, a fim de estilizar os elementos de nossas páginas de forma padronizada, responsiva e ágil. Nos arquivos de JavaScript, teremos a possibilidade de tornar os elementos dinâmicos ou com animação. Em ambos os recursos, os desenvolvedores precisam aplicar os recursos no projeto e utilizar as classes do CSS em seus elementos da página.

Como você pode ver na imagem acima, e também no site, há algumas opções diferentes para aplicar o framework em nosso projeto. Em resumo, temos a opção para baixar através de gerenciadores de pacotes ou usar o BootstrapCDN, onde você não precisa baixar nada. Com o BootstraspCDN, os recursos ficam hospedados em um servidor e precisamos apenas inserir os devidos links no head do HTML e pronto: o Bootstrap já faz parte de seu projeto.
