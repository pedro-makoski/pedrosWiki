## Tags HTML para tabelas
- **Table:** Dentro da tag table, você coloca tudo o que você vai definir na tabela. Pode ser dividida em thead, tbody e tfoot. 
	- **Thead**: Deve ser a primeira tag, tem a função de agrupar os elementos do cabeçalho.
	- **Tbody**: Deve ser usado depois do thead, ela serve para agrupar as linhas principais da tabela.
	- **Tfoot**: responsável pelo rodapé da tabela. E deve ser colocado por último. 
- **Tr**: responsável por criar as linhas de uma tabela.
- **Th**: Função de delimitar as células, de forma que possa dar um título a uma célula, delimitando-a.
- **Td**: Onde se coloca os dados, é onde fica os itens dentro de uma célula.
