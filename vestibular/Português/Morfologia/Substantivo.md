É a palavra responsável em nomear as coisas reais e irreais.
# Simples x Composto
Simples - 1 Radical
Composto - Mais de um radical
# Comum x Próprio
Comum - Designa algo generíco.
Próprio - específica alguma coisa.
# Concreto x Abstrato
Concreto - Palavra que não precisa de outra para existir.
Abstrato - Sentimentos e palavras derivadas de verbos.
# Primitivo x Derivado
Exemplo:
Primitivo - Dente
Derivado - Dentista, Dentadura...
# Substantivo coletivo 
Designa coisas iguais.
ILHAS -> Arquipélago
CHAVES -> molho.
# Gênero
## Biformes
Duas formas de apresentar masculino e feminino.
## Uniformes
Existem três possibilidades:
- **Comum de dois gêneros:** o gênero é definido por uma palavra externa, geralmente um artigo.
- **Sobrecomuns**: a mesma palavra serve para dois gêneros. Exemplo: A criança. 
- **Epicenos**: As palavras epicenas determinam o gênero. Exemplos: O tatu fêmea/o tatu macho.
