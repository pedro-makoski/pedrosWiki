O modelo pode variar de acordo com o projeto. E tem como parte importante para o desenvolvimento.
- Orgânico: É feito uma parte inicial, que vai a partir dela vai se desenvolvendo aos poucos. Onde no processo é possível ver pequenas vitórias, que ao longo forma algo grande.
- Impressora 3D: É feito camada por camada, sem visualizar o progresso a parte.
# Over Engineering 
É quando você faz no modo impressora 3D. Complicando de mais algo que poderia ser simples.
# Feature Creep
Quando o projeto tem tanto recurso, mas tanto que atrapalha no desenvolvimento.
