# Onde usar o Go
Tem aplicações de banco de dados, e backend. Pode ser usado para criar APIs de entradas e respostas. O Go é usado em várias áreas diferentes, originalmente ele era e é utilizado para controlar processo mais baixo nível, controle de kernel, e afins. Controlar middlewares e enfim. 
# Benefícios
É muito comum, tem standart libraries em Go, para muitas das coisas que você pode fazer. Então você não precisa baixar as maiorias das coisas, pois já estão baixadas. As coisas são muito mais simples, porém as vezes em Go, é necessário criar suas próprias funções, as vezes tem mais código, mas fica ainda sim, mais simples e menos custoso.

Uma das maiores simplicidades, é que por mais de ter exceções, você pode criar executáveis para diversos sistemas operacionais diferentes, e sem necessidade de dependências. Mas pode haver exceções, as vezes é possíveis o binário linka com outros elementos de rede, por exemplo, do sistema operacional. Mas isso é opcional, você pode fazer com que o compilador não crie dependências, mas é sempre bom verificar no final. 

É simples, por exemplo, não tem herança, é tudo por composição. Muitos gostas do modelo de concorrência do Go lang, que pode ser separado em blocos, e conectar entre eles, com canais.
# O porquê da sua criação 
Para facilitar e otimizar o processo de compilação, dificultado pelas linguagens c e c++.
