# Alotropia
Propriedade no qual um elemento químico forma substâncias simples diferentes.
Os elementos alotropos tem atomicidade diferentes.
Ex: Oxigênio pode ser O2 e O3
O arranjo espacial de substâncias alotrópas, é diferente.
Essas substâncias alotropas diferentes podem ter propriedades diferentes.
