# O que é?
O JS é uma forma de rodar JS fora do navegador. É um ambiente de execução JS, ou JS runtime. 
# O que dá para fazer, com execuções locais no navegador:
- Criação de servidores e APIs. 
- Leitura e escrita de arquivos.
- Compilação de código.
- Automatização de processos.
# Importante
Nem todas as funções do node estão nos navegadores. Nem todas as funções dos navegadores estão no node.
# Obter versão do node
```sh
node -v
```
ou 
```sh
node --version
```
# Executar programa em node 
```sh
node caminho/do/arquivo
```
# Executar node sem criar os arquivos
Abra o software do node. Ou execute `node` apenas, no terminal.
# Evitar erros do node
No power sheel como administrador, execute o seguinte comando:
```bash
Set-ExecutionPolicy RemoteSigned
```
E logo após do enter escreva s e depois enter de novo.
