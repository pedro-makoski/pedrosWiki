## MMC
O MMC é o mínimo múltiplo comum, que seria o menor valor que é múltiplo por todos os números. 
Para calcular acesse:
1. Acesse: [[https://www.rantool.com/funcoes/Calculos/Calculadora-de-MMC-e-MDC/?mode=mmc|Calculadora MMC]]. 
2. Digite os valores. Para aparecer outros inputs comece digitando no atual. 
3. Depois clique em ver resultado, para ver o MMC.
## MDC
O MDC ou máximo divisor comum, é o maior valor possível de dividir entre vários valores. Pode ser usado para simplificar frações. 
1. Acesse: [[https://www.rantool.com/funcoes/Calculos/Calculadora-de-MMC-e-MDC/?mode=mdc|Calculadora MDC]]
2. Digite os valores. Para aparecer outros inputs comece digitando no atual. 
3. Depois clique em ver o resultado, para ver o MDC.
