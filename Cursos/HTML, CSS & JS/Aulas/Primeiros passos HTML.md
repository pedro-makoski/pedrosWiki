# Algumas tags

## h1

```HTML
<h1>Ola, mundo!</h1>
```

Coloca um Titulo principal, ou seja titulo de nivel 1.

  

## p

```HTML
<p>Lorem ipsum dolor sit amet consectetur adipisicing elit. Molestias ratione dolores dolore, ducimus hic assumenda similique? Repellendus error vero cupiditate obcaecati voluptatum pariatur, tempore omnis! Porro perferendis a ipsa maiores.</p>
```

Cria um parágrafo de texto.

## hr

```HTML
<hr>
```
