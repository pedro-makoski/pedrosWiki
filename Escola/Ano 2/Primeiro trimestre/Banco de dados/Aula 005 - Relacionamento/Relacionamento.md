Na notação (x, y), o x se refere ao que está vindo e o y o que está do lado. Quantos x tem y. 
Temos:
(1, 1): 1 x tem 1 y
(1, n): 1 x tem vários y
(n, n): um y tem vários x e 1 x tem vários y. Para representar esse corretamente cria-se uma entidade que relacione essas duas entidades.
# O problema da relação n para n
A relação n:n é impossível de se realizar em apenas duas tabelas interligadas. Por isso criamos uma nova entidade, que relaciona duas entidades a uma outra entidade. Pode ser nomeado como A_B ou A:B.
# Geral
Um relacionamento é uma associação entre duas entidades, os dados devem ser armazenados e estarem relacionados na base de dados para que possamos utiliza-las eficientemente. 
Um relacionamento é uma representado por um losango com o nome do relacionamento no centro. O nome do relacionamento representa a relação que existe entre os objetos das entidades. O nome do relacionamento pode ser um verbo, como por exemplo: pertence, leciona, estuda possui, etc. Ou também pode ser uma composição de nomes das entidades. Como por exemplo `aluno-turma`.
Um relacionamento pode ter atributos. Esses atributos são denominados de atributos descritivos.
