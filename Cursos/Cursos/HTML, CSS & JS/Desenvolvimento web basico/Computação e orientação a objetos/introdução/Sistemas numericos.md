## Decimal
Algarismos formados por grupos que utilizam os algarismos que vão de 0 a 9. Esses grupos podem ser unidades, dezenas, centenas, unidade de milhar, dezena de milhar e assim vai, esse agrupamentos se baseiam a partir de 10, ou seja unidade(0 a 9) é 10^0, dezena 10^1(10 a 99), centena 10^2(100 a 999), unidade de milhar 10^3(1000 a 9999), e assim vai.
## Sistema binário 
Diferente do decimal o sistema binário possui a base 2, temos apenas 0 e o 1 de algarismos, ou seja só temos dois números para representar os demais.
![[Pasted image 20240712134143.png]]
Perceba que começam a aparecer kilobytes, megabytes e gigabytes, a partir de quando o expoente é dividido por 10.
Perceba-se que quanto maior é o expoente, maior fica a possibilidade de variações em grupos de binários. E por isso que sempre quando acrescentamos 1 no expoente a quantidade desses grupos possíveis como vimos nos grupos decimais, e maior fica os números que pode se ter.
![[Pasted image 20240712135146.png]]
Variações são as quantidades de bytes que o sistema pode representar. Por exemplo, o sistema de 8 bits, 2^8 mostra, como vimos antes, o número que pode ser representado pelo computador, que é 256 bytes, ou bytes de -128 até 128.
Por exemplo o sistema de 8 bits, pode-se representar 256 números(de 0 a 255).
## Sistema hexadecimal
Possui 16 algarismo, sendo eles os algarismos de 0 a 9, e as letras de A até F. Permitindo com que os números fiquem de forma mais curta.
