Existem três tipos:
- Seleção simples
- Seleção composta
- Seleção encadeada
# Seleção simples
Existe apenas um caminho possível. Apenas o if, sem o else.
```python
if condicao:
	# Código
```
## Estrutura composta
- Comparação: compara dois valores
- Condição: toda a expressão do if.
- As comparações compostas, vão da esquerda para a direira, por exemplo, true and false or true, vai ser true.
# Seleção composta
IF e depois o else. É um ou outro. 
Estrutura:
```python
if condicao:
	# se condição for verdadeira
else:
	# se condição for falsa
```
# Seleção encadeada
Duas ou mais condições. O elif usada, é e mesma coisa que um if dentro do else na condição anterior.
Estrutura:
```python
if condicao1:
	# Se condição 1 for verdadeira
elif condicao2:
	# Se condição 2 for verdadeira
elif condicao3:
	# Se condição 3 for verdadeira
else:
	# Se nenhuma condição for verdadeira
```
Essa estrutura pode variar de caso a caso.
