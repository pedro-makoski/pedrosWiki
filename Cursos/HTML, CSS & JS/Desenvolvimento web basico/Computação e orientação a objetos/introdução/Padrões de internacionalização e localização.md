No mundo, em diferentes países, há diferentes formas de representar os dados. Nos estados unidos, por exemplo, a data é mês/dia/ano, a moeda é em dolars, e o horário vai de 0 a 12, podendo ser AM(antes do meio dia) ou PM(depois do meio dia), essas siglas são originadas do latim.
## Fuso horário
O horário é sincronizado por um servidor central, que respeita um protocolo específico chamado **NTP** (Network Time Protocol). Já o fuso-horario é implementado pelos computadores através do UTC(_Universal Time Coordinated_ ou Tempo Universal Coordenado), o fuso-horário aqui no brasil, por exemplo, é de menos 3(-3), ou seja, a partir do NTP, é descontado 3, para obter o horário certeiro.
## Data
Em alguns lugares é dia/mês e ano, outros é mês/dia/ano.
## Números
Alguns lugares é a virgula com separador decimal, e ponto como separador de milhar. Em outros lugares é o inverso, como virgula como separador de milhar, e ponto como decimal.
## Localização 
A forma de representação dos valores, depende da localização ou locale. Cada linguagem de programação ou plataforma, tem uma forma de representar. Existe uma tabela para isso. Aqui no Brasil o código de locale é pt-BR, que significa português do Brasil. Ou por exemplo, os estados unidos que é en-US. Ou portugal que é pt-PT, por exemplo.
Clique [aqui](https://pt.wikipedia.org/wiki/Predefini%C3%A7%C3%A3o:Tabela_de_locale) para ver o lacale de cada país. Assim quando o locale é definido ou a linguagem(language) é definido, as configurações vão para a daquele país.
