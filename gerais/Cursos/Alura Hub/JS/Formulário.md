# checkValidity()
Permite saber se um formulário está com todos os campos corretos, como definido no HTML. 
```js
if(!elementoFormulario.checkValidity()) {
	alert("Por favor preencha todos os campos da transação");
	return;
}
```
# reset()
Limpa os valores do formulário.
# .value
Valor do texto dentro do input.
