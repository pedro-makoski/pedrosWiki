A partir de valor determinado de iterações, faça algo, até a condição ser atingida. 
# Código C
```c
int i;
for(i = valor_inicial; condicao_para_continuar; faca_isso_toda_vez_normalmente_imaismais) {
	// código para toda iteração.
}
```
```c
int i; 
for(i = 0; i<=5; i++) {
	printf("\n%d", i);
}
```
Resultado:
0
1
2
3
4
5
# FlowGorithm 
![[Pasted image 20240930163330.png]]A variável é onde vai ficar as iterações, como por exemplo o cont, ou i. O valor inicial, coloca o valor que vai começar, e o valor final, seria o <= valor_final. Crescente é i++, o decrescente i--. O valor de incremento ou decremento, seria i = i + valor_de_incremento, ou para decrescente i = i - valor_de_incremento.  
![[Pasted image 20240930163637.png]]
O i <- 1 até 100, indica que vai do 1 até o valor 100.
