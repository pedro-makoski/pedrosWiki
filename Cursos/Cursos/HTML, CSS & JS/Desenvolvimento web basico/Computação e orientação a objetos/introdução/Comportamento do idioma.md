Existem várias formas de caracteres, que são adotadas em diferentes idiomas, as vezes alguns idiomas incorporam caracteres de outros idiomas, como por exemplo, no português podemos usar letras gregas, como o pi. Para representar esses caracteres no computador existem tabelas.
## Tabela ASCII
A tabela **ASCII** (_American Standard Code For Information Interchange_ ou Código Padrão Americano para o Intercâmbio de Informação), foi desenvolvida a partir da década de 60, para que os computadores pudessem representar os caracteres.
![[Pasted image 20240712145715.png]]
A tabela ASCII utiliza apenas 7 bits, ou seja existem apenas 128 números possíveis. Ou seja, são 128 caracteres possíveis, sendo:
- 95 sinais gráficos: letras do alfabeto, sinais de pontuação e matemáticos.
- 33 sinais de controle: delete, espaço, enter e etc.
Essa tabela é bem limitada e básica, mas é usada em todos os computadores, que precisa de uma mínima interface textual ou numérica.
## Unicode
O Unicode é um padrão de escrita que pode representar letras de qualquer sistema de escrita existente. Ele é composto por:
- 138 mil caracteres.
- Conjunto de diagramas de código para referencia visual.
- Uma metodologia para comunicação.
- Um conjunto de codificações padrões de caracteres.
- Uma enumeração de prioridades de caracteres com caixa alta e baixa.
- Um conjunto de arquivos de computador com dados de referencia.
- Regras de normalização, decomposição, ordenação alfabética e renderização.
O padrão unicode é mantido por várias empresas de tecnologia. Este padrão define vários outros métodos e tabelas de codificação, a tabela mais conhecida é a UTF-8.
### UTF-8 - um exemplo de charset
Baseada em 8 bits, compatível com ASCII, e pode representar qualquer caractere universal padrão do Unicode. Sendo muito utilizado, em coisas como por exemplo, Emails, página WEB e etc. Ela aceita palavras com acento.
