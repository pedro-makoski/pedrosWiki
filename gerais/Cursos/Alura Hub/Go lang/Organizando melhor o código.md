# Pasta cmd
Contem o arquivo main.go. É lá onde fica os pontos de entrada da aplicação. Binários também.
# Pasta internal
Contém os detalhes internos dos sistema.
Possuis as pastas:
- **Data**: trabalha com a base de dados, e a conexão com o banco. 
- **Handler**: trabalha com os controllers, do gin.Context.
- **Models**: trabalha com as entidades.
